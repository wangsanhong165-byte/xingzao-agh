形造：从源码部署与运行

English | 简体中文 · 项目首页

本文针对 **Windows x64 上新克隆的 GitHub 仓库**。仓库包含源码、样例和执行记录，不附 Python 环境、切片器程序、模型权重、私人任务数据库或账号。安装过程需要访问 GitHub、PyPI、PyTorch 和 Hugging Face。

目标需要准备阅读步骤

执行新的AGH制造任务上述环境、Git、AGH编译工具和本人的模型账号第1、3～4步
图片建模与上色上述环境、兼容的NVIDIA GPU和驱动，以及上色扩展的CUDA编译工具第1、3～6步

已有完整GPU平台为 Windows 11、RTX 5060 Laptop 8 GB显存、16 GB内存、Python 3.12、Torch 2.11.0+cu130。CPU制造检查无需CUDA或混元权重。完整安装建议预留约40 GB磁盘空间，其中形状与纹理权重约13 GiB。其他软硬件组合需单独验证。

第1步：克隆与复核已有结果

在PowerShell执行：

git clone https://github.com/wangsanhong165-byte/xingzao-agh.git
cd xingzao-agh
npm.cmd ci
node tools/review/run.mjs

用浏览器打开仓库根目录的 复核报告.html。预期：原件直立和边界修正案例被拒绝；正常修正和原件侧放通过；摄影外观保护案例的区域支撑路径减少约77.33%。“复核通过”表示这些判断与记录一致，不表示所有候选都可行。

这一步不调用模型、无需Key或GPU，部分网格探针使用已有缓存。GitHub不直接渲染HTML报告，在线查看请从首页进入“结果与证据”。

第2步：重新生成标准件并切片

准备Python 3.12 x64后，在仓库根目录执行：

py -3.12 tools/setup/reproduce.py environment --kind cpu-review
py -3.12 tools/setup/reproduce.py assets --scope slicer
& .\data\reconstruction\env-torch-readonly\Scripts\python.exe tools/setup/reslice.py

安装器下载固定版本CPU依赖和PrusaSlicer 2.9.6。最后一条命令生成新的STL和G-code，并打开结果页，文件保存在 data/reproduction-runs/。它验证标准灯柱的重新生成与实际切片，不调用图片模型或AGH账号。

第3步：准备专业工具、AGH与模型账号

安装Git、VS2022 Build Tools的“C++桌面开发”及Windows SDK。随后在仓库根目录执行：

py -3.12 tools/setup/reproduce.py environment --kind cpu
py -3.12 tools/setup/reproduce.py assets --scope core
& .\data\reconstruction\env-torch-readonly\Scripts\python.exe tools/setup/check_runtime.py --kind cpu
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/setup/agh.ps1 -Action Build
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/setup/agh.ps1 -Action Serve

CPU检查应显示 meshImport: true、imageProcessingAvailable: true。Build获取固定AGH提交 ec7ebbdb36e7658d2a121c3ba5113e850b16cb63，应用 agh-adaptation/ 的适配，通过npm调用pnpm 10.34.5完成构建。脚本拒绝覆盖版本冲突的源码或运行目录。

保持Serve运行，按终端地址打开AGH，在Provider设置中配置**本人的模型账号**、测试连接并保存默认账号。已有配置使用 **CommandCode**，Base URL为 https://api.commandcode.ai/provider/v1，模型为 deepseek/deepseek-v4.1-flash；项目也支持已配置的Agnes AI路由 agnes-3.0-flash。其他模型路由需修改并验证白名单。账号权限和额度以提供方为准。

另开PowerShell，进入同一仓库目录，停止此专用AGH实例、安装插件并重启：

$env:AGH_HOME = Join-Path $env:USERPROFILE '.agh-print-detail-v2'
$env:PHOTO_CAD_AGH_HOME = $env:AGH_HOME
$env:AGNES_PROFILE = 'local-dev'
node data/agh-runtime/agnes.mjs daemon stop --profile local-dev
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/setup/agh.ps1 -Action Plugins
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/setup/agh.ps1 -Action Serve

Plugins完成4个业务插件的安装、信任、启用与快照固定。Key保存在本人的AGH私有设置中，不复制开发机账号目录，也不将Key提交到Git。

第4步：启动工作台并执行制造任务

另开PowerShell，在仓库根目录执行：

$env:PHOTO_CAD_AGH_HOME = Join-Path $env:USERPROFILE '.agh-print-detail-v2'
npm.cmd start

打开 **http://127.0.0.1:4337/**，保持AGH与工作台进程运行：

1. 进入“细杆检查”，选择“导入自己的STL / GLB”，导入 case/source-original.stl。

2. “目标最长边”填写 **30 mm**，检查导入后确认尺寸 **12 × 8 × 30 mm**，继续细杆检查。

3. 杆轴选择 **Z轴**，保留 **0.2 mm径向、20 mm³新增体积**预算，放大画布并点选杆身中段。

4. 确认 **0.25 mm半径**和 **Z=2到28 mm** 的完整轴线，开始打印方案检查。

5. 等待五姿态比较与结果重检。成功时下载STL，通过“查看姿态任务”下载已验证G-code。保存任务URL可再次打开结果。

就绪检查：

node tools/review/preflight.mjs --mode offline
node tools/review/preflight.mjs --mode live

offline检查本地工具和文件，live另需账号与插件。新执行以任务完成并交付已验证文件为准。

第6步：编译上色扩展

GitHub克隆**不含预编译原生wheel**。针对已有Torch/CUDA栈，准备CUDA Toolkit 13.0和兼容驱动。打开 **x64 Native Tools Command Prompt for VS2022**，进入仓库目录，执行以下 **CMD命令**；CUDA安装路径按实际情况调整：

set "CUDA_HOME=C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v13.0"
set "CUDA_PATH=%CUDA_HOME%"
set "PATH=%CUDA_HOME%\bin;%PATH%"
data\reconstruction\env-texture-probe\Scripts\python.exe tools\setup\build_native.py
data\reconstruction\env-texture-probe\Scripts\python.exe -m pip install --no-index --no-deps --find-links data\setup\wheels custom-rasterizer==0.1 mesh-processor==0.0.0
data\reconstruction\env-texture-probe\Scripts\python.exe tools\setup\check_runtime.py --kind texture --gpu-smoke

检查应显示 textureImport: true、nativeExtensions: true、rasterVisiblePixels > 0。构建脚本在源码副本中使用已有Windows/sm_120设置。其他Torch/CUDA/GPU组合需重新构建并验证。

返回工作台，上传正、侧、背图，确认侧视方向和尺寸后生成白模；可选进入彩色审阅并上传插画参考。已有几何也可以进入外观保护或细杆检查。请使用有权使用的图片；case/skull-input-front.png、skull-input-left.png、skull-input-back.png 为公开许可样例，来源与处理记录见 case/skull-input-manifest.json。

排错与执行记录

现象检查方法
页面能开，任务无法运行检查AGH Serve、模型账号、4个插件和CPU工具；图片阶段另查GPU资产
找不到以前的演示任务私人历史任务不随仓库分发，先看在线结果或随仓库样例，再创建自己的任务
4337端口被占用检查重复启动的工作台；业务插件使用固定端口
文件身份不一致核对固定版本与路径，不关闭校验
上色扩展失败匹配Python/Torch/CUDA/VS版本，检查光栅器烟测
GPU显存不足关闭其他GPU任务，降低允许的生成/上色设置，重新执行并检查结果

新任务和资产写入 data/；AGH记录使用本人的专用home，可从AGH Web界面导出。已有官方界面导出在 evidence/agh/。

如需为同平台机器预下载Python依赖，可执行 py -3.12 tools/setup/reproduce.py wheels --kind gpu --destination data/setup/wheels，再用 environment --kind gpu --wheelhouse data/setup/wheels 安装。模型、AGH构建依赖、切片器和原生扩展仍需按前文准备。
