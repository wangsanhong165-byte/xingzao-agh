# 项目提交文案（暂拟，未提交）

**暂拟名称（需与报名作品名称完全一致）：** 形造：三视图建模与打印验证

**作品简介（≤50字符）：** AGH驱动三视图建模与打印细节修正，以切片刀轨复核关键结构。

**问题来源与目标：** 三维网格用于FDM打印时，细杆等结构可能在切片后缺少连续挤出路径。项目探索如何在固定尺寸、关键孔道和材料增长预算下，发现打印细节风险、提出受约束修正，并用几何检查及实际切片刀轨判断交付是否满足声明条件。当前量化完整案例为原创参数化路灯设计，不声称来自真实客户或已经实物打印。

**作品与实现：** Web工作台接入原生Agnes Harness（AGH）工具链；本地模型按实际任务运行，工具读取输入网格和用户约束，生成候选后进行独立几何/切片复核。完整路灯案例固定12×8×30mm外形、定位孔、杆段、径向增长≤0.2mm和新增体积≤20mm³。原0.5mm杆未满足固定虚拟PrusaSlicer设置下的表面与中心线刀轨条件；AGH候选0.6mm和0.7mm被拒绝，0.8mm候选通过独立复查，整体外形和孔道保留。该候选新增约7.96mm³材料，切片估算0.69g/557秒；CAD半径对照亦能通过，未证明优于CAD模板，不能称省料收益或设计创新。

**反馈与停止样例：** 同一案例中0.02mm径向预算没有可行候选，系统停止且不交付；过细的0.6mm与连续性不足的0.7mm被拒绝。曾发生旧采样规则误放0.7mm候选，项目保留该反例，并补充依据实际挤出路径检查整段中心线的连续性。该验证约束单一直圆杆，不代表任意曲面、空心/弯曲杆、机械强度或实物打印。
