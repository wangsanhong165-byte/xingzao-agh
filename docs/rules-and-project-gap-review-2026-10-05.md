# 赛事要求与项目缺口核查

2026-10-05 对照[赛事官网](https://agnes-ai.cn/hackathon)、用户给出的[官方飞书指南](https://agnes-ai.feishu.cn/wiki/QNK6wKOD7ifkxHkJxoycb1MXnwl)、此前提供的全文和项目实际验收记录。此文件是当前取舍依据，不是提交已完成或获奖预测。

## 来源与核查范围

- 官网为动态页面，本轮匿名 HTTP 取得官网 HTML 及该 HTML 实际引用的页面 bundle，读取六章条文、评分表和提交组件已发布的字段约束；没有登录、填写或提交表单。原始文件存本机 data。
- 飞书匿名 HTML 包含公开文档块。本轮按根 children、表格行列顺序提取127条文本，包含对象、统一命题及前部参考方向；有76个引用块未随公开快照加载，故**没有完成当前飞书全文复核**。不把此前用户贴出的后半全文冒充本轮读取结果。浏览器读取和Exa补充读取均未成功，不读取账号Cookie或绕过访问限制。
- 飞书当前可读开头写明须使用 AGH；官网介绍、3.2允许其他合法模型，官网2.4和4.2还保留旧Agnes措辞。结合用户提供的工作人员明确答复，继续执行模型不限、AGH为核心底座的方案，保存该答复来源；不再让旧模型限定反复打断开发。申报仍逐项如实记录实际模型。

## 对产品定位的影响

统一命题包括科学、工程和设计任务。现有照片建模与打印反馈方向可以扣题，重点在明确目标、运行结果及评价。不能把“实际应用”自动等同于必须做承重零件、热力学仿真或高精度装配，也不能因一个3D文件能打开就认为目标已完成。

本科组权重：问题价值20%、任务完成度与正确性25%、AGH/模型执行闭环20%、技术深度10%、验证与异常10%、创新与发展15%。前三项合计65%；若队伍归入硕博组，技术深度25%、验证20%，需要按实际报名组别展示，不混用权重。

参考方向可以组合，不能把D3当成独立排名赛道。也不需要为了“用足AGH”添加很多没有任务意义的分支；应展示反馈如何改变后续动作，以及修改后是否真正符合原要求。

## 现有能力与最关键缺口

| 要求/评价点 | 当前实际证据 | 缺口与处理顺序 |
| --- | --- | --- |
| 明确的问题来源与任务目标 | 已有生成、切片、局部特征保护、预算修正 | P0：收敛一个完整对象和明确使用目的；保留发散比较，不直接照搬Gemini的旋钮/卡扣排序 |
| 核心任务真正完成 | AGH运行及可下载网格已验证 | P0：把“文件通过”与“满足使用要求”分开；骰子点窝还原、240k人物颜色均未通过效果验收 |
| AGH连续执行与反馈纠错 | 重建、姿态、细杆修正均有真实原生调用；修正曾依次失败再通过 | 已有较强基础；需要在完整对象上复现，而非只展示小型受控杆件 |
| 对比与专业验证 | 固定配置真实G-code、局部实体与通道核查、交付独立复查 | P0：增加合理CAD/现代切片器基线，记录收益、代价与无改善；刀轨证据不等于实物装配或强度 |
| 正常、边界、失败 | 有预算不足、源变更及全部候选不合格的真实记录 | P1：统一为同一发布版本和主应用的三类样例，不仅汇总不同模块历史运行 |
| 易于使用 | 页面串联、恢复和下载已存在 | P1：中心线、坐标范围仍依赖专业输入；优先做可视选取/核对，降低用户理解成本 |
| 创新与价值 | 有带保护要求的方案筛选及同源有限修正 | 尚未证明用户收益；已有相似工具不代表不能做，但不能把现成切片能力算成独创 |
| 可复现作品 | 本机环境可运行，源码和原生边界补丁有记录 | P1：干净环境启动、依赖/许可清单、合法资产获取方式和轻量样例包仍需验收；localhost不供异地评委访问 |

### 当前决定

1. 先比较少量具体任务，选择可以用现有工具做出完整结果的一项。候选不必限于报告推荐的配合件；文创/模型制造交付、定制小工装或立体设计任务均按相同标准评估。
2. 入选条件是能解释目标用户、输入来源、交付用途、合理基线和一个量化验收方法；不以故事板预设的省料率、成功率或承重倍数作证据。
3. 首个完整对象对照完成前，头发专项暂停，颜色保持实验功能；不继续安装一串新模型，也不全面展开旋钮、卡扣、热力学和多场仿真平台。
4. 先验证普通方案的真实问题，再让AGH据反馈调整；如果现代切片器默认功能已经解决，就记录这一结果，寻找剩余问题，不人为削弱基线。
