## 接入方式

通过 AGH 官方 ConfigurationService 验证模型目录并保存配置，复用本机已有凭据。私有 Home 的凭据读取与 Windows ACL 校验保持有效，没有将 Key 放进页面、代码或执行证据。重建与姿态 runner 从已验证配置取得 provider、route、model，并在请求前通过 CLI 显式绑定；任务参数不能自行覆盖模型。

当前已审本机提供商仍限定为 Agnes 与 CommandCode V4.1；“赛事模型不限”不等于开放用户输入任意执行地址。后续添加模型时先验证供应商接口、工具调用、图片输入、执行记录和成本，再接入相同任务流程。

语言模型负责理解和调度，Hunyuan3D-2mv 仍负责三视图几何生成；PrusaSlicer 与实际几何检查继续提供验收依据。切换语言模型并不能直接恢复生成器缺失的发束。
