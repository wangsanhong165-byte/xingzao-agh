# 颜色试验：有限收益与停止条件

用户明确：头发、颜色都是设想，由开发方自主验证，有价值才投入；没有充分收益可停止。头发专项保持暂停，不把试验结果当成必做产品规格。

## 实际试验

读取已经验收的 240000 面 STL（源 SHA `8f09708db944f80a3fcdfb0b086e00eb0a83038f668a5a5d58f492e6894be3c9`），使用原正/侧/背 PNG 做 CPU 正交投影顶点上色。侧参考从 +X 观察，角色面朝图像左；旧渲染记录中的 −X 是另一侧，原记录不改写。

输出使用 glTF COLOR_0，图像 sRGB 先转换成线性颜色；这是顶点颜色，不是 UV 贴图、专业纹理生成或真实材质恢复。输出 GLB 保留源局部三角坐标，节点矩阵把 Z-up 毫米转换至标准 Y-up 米。重新导入 GLB 的有向 float32 三角坐标指纹与源一致，节点矩阵单独核对。颜色没有改变制造 STL。

保守样例要求法线与相机方向夹角不大于 60°，并进行实际网格 first-hit 遮挡检查。结果中 32.63% 顶点可取到有效参考颜色，其他保持中性灰。该比例不是表面积覆盖率，也不是颜色正确率。原图仅 140～155×237，摄像机未经标定，bbox 对齐只是启发式。

## 目视与独立审阅结论

正面更容易辨认蓝色头发、脸、围裙与裙装，侧/背整体主要色块方向合理；未观察到大规模前后镜像串色。侧面、未见侧与饰物边界存在大片灰区、颜色断裂及黑白斑，模型原有几何毛刺仍然存在。

**决定：** 保留为辅助识别/审阅实验，不作为完整上色功能接入当前交付，不继续反复调 CPU 投影。它没有解决缺失发束，也没有证明真实材质或彩色打印。真正的完整上色需要更好的多视图对应关系或独立专业纹理管线。

产物和五视角实际 Blender 渲染保存在私有 `data/color-experiments/normalizedstl-vertex-color-20261004-facing60/`；源图、GLB、渲染图不进入源码提交。渲染器由 Blender glTF 导入执行一次转轴，核看包围高度约 0.1 m，未把毫米当作米或重复旋转。

## 复现与验证

`tools/reconstruction/project_vertex_color.py` 使用现成隔离 Python、NumPy、Trimesh、Pillow、SciPy 和 Rtree，没有下载新的纹理模型或修改父环境。测试覆盖朝向、遮挡、透明未知、白背景、颜色线性编码、源几何保持和 GLB 再导入；临时测试目录放在项目 data 下，不变更用户 Temp 权限。

CLI 需要实际源 STL SHA、三张本地视图和新的 experiment id，完整参数见 `--help`。成功运行只证明颜色附着与几何文件合同成立，是否对产品有价值仍需看实际多视角结果。
