# 人物头发几何：当前诊断与实验

## 判断

原始与简化网格的同视角渲染均缺少发束分层。主要问题已经发生在 Hunyuan3D-2mv 的生成阶段，不能依赖后续切片“恢复”不存在的形状。

将提取分辨率从 256 提高到 384，刘海边缘和表面更平滑，但后脑仍是较大的连续曲面，没有明显恢复参考图中的发束分层。当前证据不足以将 384 设为默认质量升级。

## 已完成的单变量对照

两次运行的三视图 SHA 完全一致，步数 25、chunks 8000、seed 12345、用户设定最长边 100 mm 不变；两次独立生成只有提取分辨率不同。没有新增专业模型、超分图或纹理。

| 指标 | 256 | 384 |
| --- | --- | --- |
| 原始面数 | 561988 | 1269488 |
| 生成阶段时间 | 102.371 s | 169.841 s |
| Torch 峰值 allocated 显存 | 5559.2 MiB | 5724.8 MiB |
| 生成报告中的原始水密性 | true | false |
| 简化副本面数 / 水密性 | 240000 / true | 240000 / true |

显存数字是 Torch 的 allocated 峰值，不是整机 GPU 占用；本次未发生 OOM，不能把研究报告的“一定显存溢出”当成实测结果。原始 384 网格的水密检查未通过，即使简化副本闭合也不能抹掉该结果。耗时含机器状态影响，不作稳定性能基准。

实验标识为 `hair-res384-reference`，原资产标识为 `reconstruction-1ac90d72-425f-4a6f-b9f8-50248baa6368-attempt1`。同材质、同镜头、无纹理的图与完整元数据存于本机 `data/hair-diagnosis/hair-res384-reference-compare/`。比较使用原始网格，未把简化过程引入第二个变量。

## 对外部研究报告的取舍

接受“区分真实几何、纹理与先验补全”“冻结非目标区域”“提取分辨率不能凭空创造缺失形状”的原则。对于“一周唯一可行路线”、精确显存数字和三视图必能恢复细节的承诺，尚无证据。

[Frosting 官方仓库](https://github.com/Anttwo/Frosting) 的主要交付是网格周围的高斯涂层与渲染表示；其训练入口使用 COLMAP 数据，官方采集建议是覆盖对象表面的多角度图像。将三张非标定插画改造成该输入、再把高斯细节固化为可靠 STL，是额外研发问题。官方依赖也包括 PyTorch3D 与 CUDA 扩展，不能按报告视为仅安装轻量渲染器即可集成。

[Hair-GS 官方仓库](https://github.com/yimin-pan/hair-gs) 要求图像、头发掩码、COLMAP 相机与稀疏点云、方向/置信图、头部数据。它导出的边或零面积可视化三角形也不等于可打印实体。现阶段不安装该整套训练环境。

当前是 Q 版人物，头部在原图占比明显高于报告使用的普通成人比例；“头部只有 40～60 像素”不能直接套用。原图仍是低分辨率参考插画，但是否存在可利用的发束轮廓应以实际图像检查为准。

## 下一项实验与停止条件

先检查能否从同一批源图得到共同纵向范围的头部裁切，不改像素、不超分、不删去需要保留的长发轮廓。若裁切必然截断重要发束，明确标为局部片段实验，不将结果当作完整发型。

实际检查已保存共同 y=[6,190) 的三张裁切及源/输出 SHA。这组图仍含部分躯干，背面下部蓝色附属结构被截断；它更像角色的尾部，不能未经确认当作“发束”。裁切并非高质量、纯头部且完整三视图的输入，暂不据此拼接替换原模型。进一步局部生成应先建立可靠的区域与相机对应关系。

有可用输入时，最多先跑一次 256 的独立局部生成，判断模型对更高的头部画面占比是否有实际收益。没有明显收益或出现严重比例/边界不一致，就停止把局部接缝集成到主流程，保留失败证据并寻找合适输入或专业生成模型。拼接、外观改善、切片验证分别验收，不能用其中一项代替另一项。

随后实际完成了共同 y=[0,135) 的上半头部诊断，保留原像素、未超分，仍用 25 步 / 256 / chunks 8000 / seed 12345，最长边设为独立展示用 60 mm。该裁切刻意截去下半长发，因此不属于完整发型重建或单变量全身尺寸比较。运行 `hair-upper-head256-diagnostic` 生成 621080 面，生成阶段 88.677 秒，Torch 峰值 allocated 5559.2 MiB；原始 STL 水密检查为 false，简化副本为闭合且通过独立导入几何检查。

实际正、侧、背渲染仍呈块状后脑，脸部新增失真，没有证明局部生成收益。原模型未替换，未拼接或提交这份片段。至此两项低风险实验均已完成，停止继续只靠提高提取分辨率或简单裁切寻找改善，下一轮应更换可靠细节输入或适合的专业几何方法。
