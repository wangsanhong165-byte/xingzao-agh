# 关键特征验收：实现与真实验证

## 已实现的行为

系统现在可以在同源四姿态比较中加入实体细杆和贯通孔的局部验收。AGH 调用的仍是原先经过安装、信任与启用的五个姿态工具；特征证据随评价结果返回，选择和交付前由服务再次检查。无关键特征的历史任务保持原语义。

实体检查采用实际网格占据与各暴露方向的首次出射表面点。总体保留率与每个非空方向的保留率均须达到声明阈值，避免平均值掩盖某一侧的缺失。孔道检查原有空腔、相邻采样中心之间的连续边及出口连接；剩余空腔比例足够且指定轴两端仍连通才能通过。支撑、裙边、空走、回抽不算永久模型。

实际 G-code 挤出使用每段 WIDTH 与 HEIGHT 构造包络。已确认的 PrusaSlicer 注释状态可以延续，无效注释清除旧值；不能推断的角色、线宽、层高、弧线、非平面挤出或采样精度不足均不能给出通过结论。

## 受控样例与真实模型调用

所有样例采用同一自动支撑打印配置。测试件主体为 20×18×3 mm，带细杆及直径 2 mm 的贯通孔。它们是程序生成并独立检查的闭合 STL，页面明确标记为导入源与演示坐标范围，不冒充照片重建或人工确认的语义区域。

| 样例 | AGH 任务 | 结果 |
| --- | --- | --- |
| 0.8 mm 细杆 | `2af44acb-29c7-410b-92a0-5b8f3d17cddd` | 四候选均通过，选择成本最低的直立姿态；细杆表面保留率 100%，孔道空腔保留率 98% 且连通，复查后交付 |
| 0.5 mm 细杆 | `bf4cf167-4298-47f3-9e07-fe449cdf73c7` | 四候选均不合格；X −30° 总体为 94.83%，但 −Y 方向仅 88.70%，未达到 90% 阈值，停止交付 |

两次运行均由原生 AGH 插件与 `agnes-3.0-flash` 完成。正常样例实际调用 8 次原生工具，边界样例 5 次；两者分别有 6 次持久化模型请求。只读账本核查与服务事件交叉对应，核查摘要保存于本机 `data/print-validation/pose-native-<任务编号>.json`。

此前一次启动失败 `dbb42cd7-3291-4392-83ef-5c04c9307c56` 仍保留，不计为成功样例。原因是本机 AGH Home 权限不符合凭据存储私密性要求；使用官方存储接口的元数据诊断确认，按目录原所有者调整额外读取权限后恢复。密钥及模型配置没有更换，未绕过凭据安全检查。`tools/diagnostics/credential-health.mjs` 只输出权限与可读取状态，不输出密钥。

## 可复查的工程约束

- 每任务最多 4 个特征，默认采样网格 32³，实体表面软件比较容差默认 0.05 mm、上限 0.1 mm。孔道检查不使用该容差放宽空腔。
- 源文件、特征声明、探针算法、探针数据、候选、配置与 G-code 都绑定哈希。交付前重新生成探针并重新评价；同步修改摘要和文件哈希不能替代实际复查。
- 导入源重新从原始输入独立归一化，验证结果不覆盖旧记录；原输入与声明网格不对应时拒绝。
- 探针 CPU 子进程使用本机隔离环境，Rtree 1.4.1 用于网格空间查询；Manifold3D 3.2.1 仅为受控布尔测试件依赖。父级 Torch 环境未改动。
- 有薄堵片、方向遗漏、未知层高、坐标错误和伪造源证明等回归用例。初期非闭合测试件也保留在私有实验目录，没有强行修成成功证据。

## 本机复现入口

依赖就绪后，在项目目录运行：

```powershell
node tools/validate-critical-features.mjs
node tools/validate-feature-poses.mjs data/critical-validation/<实验目录>/pin-0.8/source.stl 0.8
node tools/validate-feature-poses.mjs data/critical-validation/<实验目录>/pin-0.5/source.stl 0.5
node tools/start-feature-demo.mjs normal
node tools/start-feature-demo.mjs boundary
```

前两个入口生成独立实验报告；姿态比较工具的参数以源码说明为准。演示入口使用本机已经保存的候选编号，新环境须先生成并导入样例，再更新入口候选编号。上述正常与边界记录可通过本机 `/poses?job=<任务编号>` 打开；静态报告与网格位于忽略的 `data` 目录，未把密钥、原始账本或用户素材加入代码库。

## 尚未证明的部分

这些数字证明采样条件下的源几何与计划挤出包络关系，不证明实际打印成功、强度、热变形或真实配合公差。实体表面保留率不是对照片相似度的评价。当前没有自动恢复人物发丝，也没有任意网格的自动局部加厚。不同直径测试件属于几何变体，不能宣称为同源不变形节省耗材。下一步先改善生成质量，再把有明确修改预算的局部修正接入同一验收流程。

## 补充：实际浏览器上传回归

补充检查发现新页面在毫米单位模式下漏传目标最长边，且误用了图片 5 MiB 限制和不存在的尺寸字段。已对齐实际导入合同：两种单位模式均明确显示并传入目标最长边、模型上限 25 MiB、读取真实 `dimensionsMm`。更换文件、单位或尺寸后，旧候选失效，必须重新检查。

实际浏览器回归先确认旧版返回 HTTP 400，修复后小型受控 STL 与约 12 MiB 的生成 STL 均通过；显示 20×18×5 mm 的真实归一化尺寸，变更尺寸后开始按钮禁用。上传仅触发导入接口，没有启动 AGH 或产生模型调用。
