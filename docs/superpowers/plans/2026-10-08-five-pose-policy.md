# 接入侧放的版本化姿态策略

目标：新首次委托自动评估已经独立验证的X−90°侧放，原件可行即交付，不继续不必要的加粗；旧四姿态任务和旧确认合同可读、可下载且不改写。

设计：保留`POSE_CANDIDATES`旧四项与默认独立姿态API；新增`fixed-five-v2`策略，由新workflow明确选择。每个新工作流冻结策略ID与五个候选ID，父姿态记录同样标策略，交付验证核对一致；缺策略的历史记录按`fixed-four-v1`解释。AGH通过inspect取得该任务的完整列表，工具schema兼容五项、服务按任务列表授权。12次工具预算足够覆盖1检查+5评估+选择/复核/提交。

- [x] 先写五项选择/四项兼容、第五项未评估不许选择、历史合同下载不变、父子策略变更拒绝等测试，观察失败后实现。
- [x] 修改姿态策略、状态机/选择上限、原生提示词和插件enum；HTTP下载及修正父姿态支持face-up，但仍以任务策略约束。
- [x] 新workflow冻结五项策略，界面根据声明显示数量；历史记录依旧显示四项。保留已完成任务的原始指标。
- [x] 更新并通过官方AGH包管理安装/信任/启用同一已审插件的新版本；不修改凭据或削弱校验。
- [x] 运行真实0.5mm原件和0.02mm预算的新策略：若侧放满足条件，必须直接交付原件，不产生修正阶段；核对原生记录、同源/hash和真实刀轨。
- [x] 针对测试、浏览器和下载复检，审查后提交；更新演示与提交包准备，明确策略改变使哪些旧结论不再适用于新任务。

不加入无限角度搜索、新模型或力学承诺；目标仍是同一软件验证范围。新任务变化不能倒改旧记录，也不能称五个候选全局最优。
