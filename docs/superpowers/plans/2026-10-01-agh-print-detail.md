# AGH 打印细节保护实现计划

> 使用 subagent-driven-development 分派独立模块，主代理两阶段审查、集成并验证。用户已授权执行，不另设重复确认。

**目标：** 完成一条真实 AGH 驱动的图片细节→几何增强→实际切片→路径复核→结果提交链。

**架构：** 固定输入与受限工具，服务维护候选身份和验证门禁；AGH基于反馈选择下一工具与可改参数。PNG/CV/JSCAD构造、独立切片与Gcode分析各自可测试，最后接入UI。

**技术栈：** Node24、项目Python OpenCV、JSCAD、Blender、现有AGH构建、真实Windows切片器。

## 本轮任务

- [x] **几何增强（Luna）**：PNG 有孔徽标、非法参数、低保真与网格分辨率门禁；OpenCV 与闭合像素单元 STL。独立受控 O 案例 IoU=0.904552、1组件1孔，实际 STL 边邻接全2，射线探针确认孔洞保留。非任意照片重建。
- [x] **切片与路径复核（Luna）**：官方 PrusaSlicer 2.9.6 portable，哈希与授权记录。模式、回抽、travel、抬 Z、床面平移均有测试；真实 O 案例基线0层、增强3层／724.895mm 局部挤出，使用相同虚拟配置。
- [ ] **AGH（Luna）**：研究合法配置SDK与package lifecycle；独立home配置Command Code模型，不打印Key。真实安装/注册工具插件；先用临时loopback工具端点与简单元数据跑规划→验证→提交AGH链，再接根服务。禁止用stub当实际运行；预算限轮次与工具数。
- [ ] **服务与界面（根代理）**：先用test验证candidate+slice+verify门禁、无AGH明确失败；实现job状态/受控API/UI，检查正常与异常。所有阶段与失败真实显示。
- [ ] **整体验证**：运行模块测试、真实AGH+切片链、浏览器操作；记录未见实物测试的边界，保存基线与增强比较，merge后保持原工作台可访问。

## 分阶段安排

- 10月1～3日：上述受控平面样例、AGH真实闭环、切片评价器。
- 10月4～7日：接专业多视图重建或任意已有网格输入，评估一个曲面局部特征；不训练通用生成模型。
- 10月8～11日：收集授权样例，完成默认工具对照、尺寸变化、失败与恢复；如能借打印机，复核少量实物。
- 10月12～14日：冻结核心行为、复现说明、3～5分钟真实演示视频与执行证据。10月15日12:00前由队长核对提交。

本计划是实施顺序而非进决赛保证。阶段一若无法产生可靠改善，停在真实失败证据并调整任务范围，不靠增加页面掩盖。
