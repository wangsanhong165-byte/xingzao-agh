# 关键特征验收实现计划

用户已授权按上一阶段计划自主推进，沿用隔离分支，不等待新的重复确认。

**目标：** 检出原网格中存在、却在真实切片刀轨中丢失的细杆表面或被封闭的孔道，并将特征验收作为姿态选择的硬约束。

**架构：** 对源 STL 的用户声明局部体积建立有界采样网格，计算实际网格占据关系。实体特征沿每个暴露方向发射射线，提取第一次离开实体的实际表面点；总体和每个方向都必须通过。孔道不仅检查空腔采样点，还验证相邻点之间及通道出口的连续线段，避免漏掉网格之间的薄堵片。将探针通过已验证的 source-to-print 矩阵与床偏移映射到打印坐标，检查实际 MODEL 挤出的宽度/高度包络；支持、空走和回抽不计入永久模型。

**技术栈：** 现有 Node/Trimesh/NumPy，隔离 Python 环境新增固定 Rtree 1.4.1（不修改父环境）；受控闭合测试件通过 Manifold3D 3.2.1 布尔运算构建；PrusaSlicer 2.9.6 与原固定自动支撑配置。

## 接口与边界

- 每个任务最多 4 个 `criticalFeatures`，每个含 `{id,kind,boundsMm,minRetention,surfaceToleranceMm,axis?}`；kind 为 `solid` 或 `void-channel`，后者必须声明 x/y/z 通道轴。minRetention 默认 0.9，范围 0.5～1；坐标以已归一化的源模型为准。
- 默认网格 `[32,32,32]`，X 最快，单元中心采样；单特征上限 32768 单元。实体目标为实际外表面方向探针，不要求内部填充实心；表面容差默认 0.05 mm，上限 0.1 mm，属于软件比较容差。孔道目标为空腔中连接指定轴两端、且不接触其他侧面的分量；不使用实体表面容差放宽空腔。
- 源特征不存在、采样不足、开放网格、未知角色、缺少线宽/高度、弧线或非平面挤出等情况不得给出成功。采样和挤出包络是软件代理，不证明实物成型、公差或强度。
- 源 STL、探针、特征声明、候选 STL、配置和 G-code 绑定 SHA。复查重算指标，不能靠同步改两处阈值或探针数据获得通过。
- 历史无 criticalFeatures 的任务保持原语义，不用新规则改写旧证据。

- [x] `src/slicer.mjs`：HEIGHT 注释与 WIDTH 一样按已验证生成器持久化；无效注释清除旧状态。

- [x] `src/critical-feature-service.mjs` 与测试：声明校验、CPU 子进程、探针文件哈希与重新计算复查；不开放任意路径或 shell。

- [x] 明确标记的 STL 导入源；从实际输入独立重建，拒绝伪造的归一化网格与摘要。

- [x] 页面文案、正常/边界/历史任务的桌面与手机浏览器验收：恢复页面无自动提交、无脚本错误或横向溢出；边界任务明确显示 −Y 88.7% 不达阈值。
- [x] 在当前隔离分支保存实现与实验检查点；私有数据、图像、模型与密钥不进入提交。

## 本轮不扩展的部分

不承诺自动理解任意照片中的精密功能尺寸，不做任意曲面自由雕刻、材料强度或热力学求解。先证明检测与硬约束可靠，再决定局部修正的支持对象和允许变化范围。
