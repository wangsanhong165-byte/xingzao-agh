# 建模还原度与真正纹理的验证计划

目标：由开发代理自主执行有预算的同图对照，验证现有生成参数是否有收益，并确认真正纹理生成的最低运行条件。沿用用户授权的独立工作区，不覆盖已提交或已验证的模型。

现有 Hunyuan3D-2mv 是已跑通的基准，尚无证据证明它是 8GB 显存设备能运行的最佳方案。CPU 参考投影上色未通过侧面质量审阅，退出正式功能；保留原始实验与失败证据。

## 取舍

提高面数、生成日志成功、切片成功均不能替代外观还原度。若两次参数对照没有明显改善，停止在现有设置上盲目加算力，转向专业候选 TripoSG 的独立可运行性测试，或更可靠的输入。TripoSG 官方 README 写至少 8GB，而模型卡写大于 8GB，不能先承诺本机可用或优于多视图基准。

无需等待 Gemini；它只补充低显存纹理编译与第三方卸载路径的资料线索，所有关键结论仍由本机运行和作者源码核查。

**用户最新取舍：** 完成本轮收尾后暂停，不接 FAL、不直接复制 image-blaster 的功能；其流程组织作为讨论参考。已完成工作与未完成部分分别记录，未启动的 Paint 大权重下载/完整生成暂不执行。原照片建模＋制造验证/修正路线保留，等待与用户交流选题和作品价值。
