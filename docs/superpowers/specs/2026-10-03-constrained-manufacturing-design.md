# 形造：受约束打印方案比较

用户已授权制定计划并执行。沿用三视图重建、真实 AGH 调用和独立几何检查；不重新训练模型，不把生成质量下降计作省料。

## 本阶段交付

同一 STL、同一尺寸、同一固定自动支撑配置，生成四个刚性姿态。独立检查每个姿态的矩阵、体积、打印边界与真实切片结果。原模型坐标中的保护 AABB 保持不变；逆变换刀轨后报告支撑包络进入该体积的近似长度。缺少角色、线宽或可靠位置证据时结果未验证。

输出候选比较、淘汰原因、所选 STL、实际切片证据和配置摘要。第一步先用实际工具证明比较可靠，再接 AGH：检查 → 比较 → 选择 → 复核 → 交付。允许基线获选、没有改善或全部候选不可行。

## 选择与验收

先过滤打印包络超限、几何/变换无效、切片失败和未验证方案。用户保护区域以明确阈值作为硬约束；在通过约束的候选中比较耗材、时间和支撑影响，不把加权评分称为全局最优。原始直立方案与其他候选完全使用同一配置。

保护区由用户指定并确认；自动生成的示范区域必须标记为示范配置，不推断成用户确认的面部或装配面。刀轨包络交集是近似代理，不能称真实支撑接触面积、表面损伤或力学强度。

## 实现边界

几何变换、刀轨审计、切片适配分离。源文件、候选文件、配置和 G-code 分别绑定 SHA；选择阶段复核文件，禁止陈旧结果交付。最多四次切片，固定姿态与配置，不开放任意路径、命令或 G-code 改写。模型 Key 与原图不进入公共报告。

## 后续顺序

1. 完成受约束比较并用受控模型和当前压力模型产生真实证据。
2. 在 AGH 中加入比较、选择与复核，页面展示候选和拒绝原因。
3. 补第二类输入与正常/边界/失败对照，检查关键特征验收的实际收益。
4. 根据真实结果整理演示脚本、复现说明和提交材料；视频和公开内容在具备真实内容后准备。

实物承重、公差成品匹配、热变形、任意照片重建精度仍需单独实验。软件验证不足以给出这些承诺。
