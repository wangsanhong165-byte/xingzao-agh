# 单根细杆受限修正设计

用户已授权自主推进既定计划与分工。本轮补足“发现缺陷 → 修改候选 → 同条件重验 → 独立复查 → 交付”，沿用当前隔离分支及 V4.1，不等待重复批准。

## 范围与取舍

选用确认中心线的直圆杆增厚。相比平面薄壁加厚，其轴线与变化预算更明确；相比任意曲面膨胀，它能够给出可复核的源保留和作用域证据。本轮不做人物发丝恢复、不把新测试件生成冒充旧网格修复、不改写已有 pose/source 证据。

输入是一条已结束姿态任务中的失败候选及其源 SHA、目标实体特征 ID、轴对齐中心线、允许变化 AABB、最大径向增量及最大新增体积。目标特征必须在真实切片评价中不合格，阈值沿用原任务。用户声明坐标与预算；演示数据明确标注程序生成来源。

## 几何算子与证明

Python 读取实际源 STL，核对 SHA、文件边界、面数、闭合性、正体积与 Manifold 状态。沿中心线至少 8 个内部截面确认仅有一条近圆形、近同心的局部轮廓；弯曲、分叉、邻近另一表面或缺失轮廓拒绝。用受限圆柱与实际网格做并集，只增加材料，不重新生成主体。

独立复查读取源和结果，计算源减结果的移除体积、结果减源的新增材料、新增材料包围盒及体积、连通分量与拓扑状态。新增部分必须位于允许 AABB 内，移除体积为零（注明数值容差）；径向增长与实际采样到源表面的距离不超过声明预算。输出文件另存，不覆盖源。原坐标和全局尺度不重新归一化。

每份证明绑定源/结果 SHA、算子源码 SHA、不可变请求参数 SHA。复查重新运行验证，而非信任同步改写的摘要。体积/距离验证是软件几何条件，不证明强度或实物打印成功。

## 工作流

新增独立 repair job 与 `@photo-cad/feature-repair-tools@1.0.0`，保留旧 pose 插件的安装完整性。五个原生工具为：

1. `repair_inspect`：读取父任务、确认源和修正范围，给出服务支持的有限半径候选。
2. `repair_evaluate {candidateId}`：对 original 或本任务新候选，用原固定姿态、同一自动支撑配置真实切片，检查关键特征。
3. `repair_apply {radiusMm}`：仅可在原候选未通过后执行，最多三次，半径必须属于本任务有限选项。每次都从原源生成独立候选。
4. `repair_verify {candidateId}`：候选通过全部条件后，重新做几何证明、源/候选探针复核、切片证据复核。
5. `repair_submit`：复查绑定同一候选与 SHA，输出实际 STL；全部不合格时不交付。

AGH 负责根据反馈决定修正半径、重试或停止。服务同时强制顺序、预算、任务 nonce 与通过条件。总工具预算 12，CLI 600 秒；不开放任意文件路径、脚本、shell 或 URL 参数。

## 特征复核

保留原特征定义与阈值，检查原源表面/孔道在新刀轨中的状态；同时针对修正后细杆扩大的观察窗口重新建立候选表面探针。仅更新被修正实体的横向采样范围，原轴向范围和阈值不变，其他特征原样保留。两套验收都通过才能交付，避免新增外表面未实际打印或补料堵孔。

## 验收与页面

从原 0.5 mm 细杆失败任务开始，对实际源网格执行修正，展示源/候选 SHA、操作半径、允许预算、新增体积、未修改区域证据、前后 STL、刀轨与特征结果。另用过小预算演示停止。受控样例只说明算子及切片闭环，人物插画保持独立失败边界。

页面 `/repair?parent=<pose-job>` 接续姿态任务，手动确认轴线/允许范围/预算，按任务状态展示过程与前后结果。恢复页面不发起 POST；未复查通过不显示交付下载。正常、边界与历史姿态页均继续可用。

## 停止与失效条件

截面不能确认为直圆杆、布尔无法得到有效闭合体、源 SHA 变化、预算超限、邻接结构合并、孔道不连通、任一特征未达原阈值、证据不能重算，均停止该候选。不会扩大预算、降低阈值或删除失败记录来制造成功。
