# UV计算尺度修正设计

三组新角色测试定位到生产纹理模型变单色的原因：交付坐标是米单位的100mm模型，xatlas在原尺度下把第二组190548面的190371面展开成零UV面积。仅UV工作坐标归一化到最长边2后，同一mesh剩2364个零UV面，UV唯一坐标462→138329；原顶点及面未改。

采用单独UV助手：在归一化工作副本调用xatlas，返回索引映射和UV，将映射应用到原始坐标。三角面float32有向签名必须不变，不放大最终模型。上游固定源码和权重不改；运行桥接明确记录项目UV配方与实际helper指纹。

先用第二组相同已生成彩色视图重烘焙，避免把重新推理变化当作修正收益。通过固定镜头实际渲染再决定接入生产；若结果仍差，保留失败、不改旧纹理。独立测试覆盖小尺度参数化、UV变换/拆点保留几何、非有限输入/零尺度及恶意映射拒绝。
