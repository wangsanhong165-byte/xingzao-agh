# 下一项竞争力改进：把第一次委托做到完整

2026-10-07 的独立只读建议。这里没有宣称建议中的新功能、用户实验或获奖结果已经实现；没有改应用代码、启动模型请求或提交代码。本轮已核对 skull 透明渲染报告：平均轮廓代理 IoU 约 0.88445、最差视图约 0.86319；主代理的人工显示特征检查另列。该结果只支持限定展示外观，不是三维真值，冻结面部保护区的制造任务仍未满足。

## 推荐：一次确认保护目标与预算，让实际失败决定后续动作

把“微缩件上的关键直杆必须留下，整体尺寸不能变，允许局部增材到指定上限”做成一个能完成的用户任务。用户选择源模型，在源预览中点选直杆、核对高亮范围与已有约束、锁定预算，然后只按一次“检查并交付”。系统依次检查姿态，必要时在同一授权内修正；无法满足要求则停止。

这项改进补的是现有流程的开头与跨阶段衔接：`/poses` 仍要求源任务 UUID 和关键特征的六个坐标；`/repair` 的一次点击是在父任务已经失败、目标特征已经申报后才能使用。用户仍要先理解坐标，再知道何时从姿态页进入修正页。相比再加一个模型，这里更直接影响问题价值、任务完成和 AGH 闭环，本科组三项合计 65%。

适用用户限定为需要处理现有网格的微缩场景/道具制作者。照片生成是源模型入口之一；生成器的还原质量必须另验。这次入口改进不能把灯柱的修正成功接到 skull 的照片成功上，伪称同一个端到端案例。

## 一天内的明确范围

1. 在姿态任务创建前提供已验证源 STL 的预览。重建页自动携带它已提交的候选；导入源继续沿用原几何检查。用户无需复制 UUID。
2. 点选仅支持当前已经验证的轴对齐、单根直圆杆。调用现有只读截面拟合，在源上显示整段轴线和实体范围；用户选择源轴方向并确认。允许修改范围与原实体保护范围分别显示，不能把增长 AABB 当作原特征定义。其他特征/孔道只读已有确认声明，不让模型猜测。
3. 用户一次确认源、整体尺度、保护定义、径向/体积预算。源、预算或范围变化使确认失效。开始后这些值不可被 Agent 改写。
4. AGH 根据返回的失败原因选择动作：已有可行姿态则交付；关键实体丢失且已确认直杆、存在允许候选，才进入局部修正；仅支撑保护冲突、能力不支持、信息不足或预算无允许候选则停止。不得在所有失败上机械地启动加粗。候选通过后仍走既有独立复查与下载。

停止说明必须写出候选集合和固定条件。例如“当前四姿态与本次允许的局部修正无解”不能缩写为“这个物体不能打印”。新发现的侧放原件解也必须展示；它尚未进入原生四姿态工具目录，不能声称当前 Agent 已经尝试或选择它。

先不做自由笔刷、人物语义分割、自动孔识别、任意曲面加厚、无限姿态搜索、打印机控制或新模型安装。实现只串接两类已有局部能力，不扩大几何承诺。

## 已有能力与需要新增的部分

可复用：`loadVerifiedImportedSource` / `loadVerifiedReconstructionSource` 的来源检查；`proposeLocalRod` 与 `rod_target_proposal.py` 的只读拟合；Three.js 预览与点击；`pose_inspect/evaluate/select/verify/submit`；`repair_inspect/evaluate/apply/verify/submit`；源/参数/候选绑定与正式交付复检。

需要新增：父任务建立前的只读拟合入口、统一的确认摘要、有限的跨阶段状态衔接，以及失败原因与下一步的可视说明。现有拟合 helper 本身不依赖已申报的 feature AABB，但当前 HTTP 调用入口依赖父任务；因此这是新接线工作，不能把现在的 `/repair` 直接称作已完成。

Agent 的价值是保留用户意图、理解工具返回的失败类型、选择后续路线与解释停止；几何真值与交付许可来自确定性检查。现有 `pose-agh.mjs` 要求读服务推荐，`repair-agh.mjs` 要求依次尝试有限半径，所以现有证据证明原生闭环，尚未证明 LLM 优于一个固定路由脚本。调用数量不作为新增智能性的指标。

## 可证伪的验收与公平基线

当日独立 −90° 对照已经改变了取舍：原 0.5 mm 灯柱不改几何也通过了表面、孔道和中心线连续性检查，切片估算 0.80 g / 346 秒；加粗到 0.8 mm 后直立为 0.69 g / 557 秒。两者都只是软件检查，不是实物结果。加粗直立使用较少材料但耗时更长、改变了局部外形；侧放原件保留原形且更快。因此 0.8 mm 不是全局必要尺寸，极小增长预算也不代表所有制造方案无解。原生四姿态失败与独立 −90° 通过应并列，不能把后者藏在备注中。

新的任务入口若继续实现，应把“优先保持原形 / 优先估算耗材 / 优先估算时间”作为可确认的目标，并明确当前可执行候选集合。若当日不扩展原生姿态目录，就先显示这个独立基线和工具范围，不让 Agent 假称已覆盖它。可验证的智能价值是依据用户目标解释并选择这些实际权衡；“必须先修杆”应退出主叙述。

冻结一个完整灯柱和一个未用于开发调参的原创网格变体的源字节、约束、打印配置与预期检查口径。第二件改变杆位置、底座/灯头布局或轴向，保持在声明支持范围内；不能只换颜色，不能遇到失败后删掉。它们均标为参数化原创网格，不冒充实拍。

用同一源与审计比较三种路径：现有多页手动流程；合理的 PrusaSlicer/CAD 人工流程；新的一次委托。PrusaSlicer 使用已启用的 Arachne 与正常自动支撑，允许其已有的姿态调整、支撑涂绘与合理薄壁设置。参数化 CAD 若同样通过就如实列出；不以加粗操作本身为独创，也不人为削弱强基线。

[Prusa 官方 Arachne 说明](https://help.prusa3d.com/article/arachne-perimeter-generator_352769)已有可变线宽和最小特征处理；[支撑涂绘说明](https://help.prusa3d.com/article/paint-on-supports_168584)已有强制/阻止支撑。因此优势必须来自完成用户任务与独立复查，不能来自“切片器不会处理薄壁/保护区域”的错误前提。

最低通过条件如下，均是目标而非已测结果：

- 正常支持任务：源选择后，0 次复制任务 ID、0 个手填坐标、1 次启动；仍须保留点选/轴方向/预算确认。最终与既有严格审计一致，不能为减步骤放松阈值。
- 反事实任务：同源至少覆盖当前候选中原件已经可行、固定姿态下预算内需要修正、固定姿态下无允许修正、仅支撑保护冲突四种情况。动作分别为交付原件、修正后复查、明确本次修正范围停止、停止/报告姿态范围无解；不得把已可行源改造，也不得对支撑冲突盲目加粗。另列 −90° 原件基线，不能把有限范围停止说成全局不可制造。
- 边界与篡改：至少覆盖非直圆杆点选和源/预算改变；0 次不合格正式交付，旧确认必失效。无法归类的失败返回未知而非默认为可修。
- 新旧流程逐项记录人为操作次数、候选结果、新增体积、连续覆盖和估算成本。若借得到两位非作者参加，交叉顺序做各两题，记录达成正确任务的时间与错误；若没有参与者，只报告受控操作计数，不称用户省时或用户研究。
- 为 AGH 加一个无模型、同工具与同候选集合的有限路由对照。若候选与停止结果相同，应明确收益来自委托与解释体验，不能宣称 LLM 提升了制造正确率。不同配置的人工基线单独记录配置与审计，不混作同配置的数字收益。

## 60 秒展示片段

0–10 秒：显示“30 mm 沙盘灯柱、整体尺寸与定位孔锁定、直杆允许径向增长 0.2 mm、新增体积最多 20 mm³”，明确源为原创参数化网格。

10–20 秒：点击源杆，确认实测轴线/范围与预算，一次启动。

20–38 秒：真实运行记录显示原生四姿态未满足目标；0.7 mm 表面采样看似达标，但中心线刀轨有断段，因此不能交付。并列 −90° 原件基线，明确加粗不是唯一解。

38–50 秒：0.8 mm 直立方案经独立复检后交付；与 −90° 原件的 0.80 g / 346 秒比较，显示自身的 0.69 g / 557 秒，解释少用料、增加时间和修改外形的代价，不宣称所有目标都更好。

50–60 秒：把预算改为 0.02 mm，旧确认失效，固定直立修正委托因无允许候选停止，正式交付关闭；说明这不否定侧放原件的独立通过结果。展示中的结果全部取实际运行；耗时超过一分钟时使用明确标注的录屏剪辑，不把回放称为即时计算。

这段只展示制造闭环。实拍主案例若通过其冻结的外观和制造要求，再单独展示同源照片链；若未通过，不以这个片段替代照片验收。

## 时间预算与停止条件

上限 8 小时：1 小时冻结任务合同/基线，2 小时试通父任务前拟合与有限跨阶段衔接，2 小时接确认与结果展示，2 小时跑上述反事实/边界及新源对照，1 小时整理证据和录制片段。不得用模型调参吞掉这一天。

第 3 小时仍不能复用现有接口完成一项绑定同源的跨阶段委托，或需要重做原生插件权限/状态架构时，停止扩展统一入口，切到备用。新网格被当前 256 轴向事件或多截面环拒绝时保留拒绝，不临时跳过保护；不得为了演示放宽到一般网格。

## 备用：不新增功能，做一项可以改变结论的对照

上限 4 小时，用上述第二个未调参的原创网格和两档预算，完整比较当前流程、正常 Arachne/薄壁配置与同约束 CAD。提前冻结特征与配置，记录失败、所需人为操作、耗材/时间估算和正式交付行为。若 CAD/切片器已满足目标，承认形造在该题没有制造质量优势；只保留它确实证明的约束跟踪、拒绝误交付和复核便利。若当前自动拟合拒绝，报告适用边界，不加入成功率分母后再移除。

这项备用比多堆几个成功截图更有价值：它能推翻“当前优势足够普遍”的假设，并给主展示一个有边界的结果。照片还原失败、灰块纹理、实物可靠性缺证据继续如实保留；不投入头发专项、全套仿真、FAL/新付费账号、克隆竞品场景编辑器或新的通用修复系统。
