# 技术结构与验证范围

形造通过Agnes Harness组织工具执行。生成、几何计算和刀轨验证分工如下：

1. **建模与上色**：Hunyuan3D-2mv生成基础网格；纹理阶段沿用已有几何。生成结果保留输入、尺度和文件身份。
2. **支撑优化**：对同一源模型比较任务声明的固定姿态，由PrusaSlicer生成真实G-code。结合线宽、层高计算支撑包络，并通过逆变换在同一源坐标保护区统计路径长度。结果同时列出整件耗材与工时估算。
3. **细杆检查**：原网格特征点与模型挤出路径比较；沿用户确认的完整中心线合并覆盖区间、检测缺口。支撑路径不作为模型覆盖。当前局部修正限于轴对齐的单根直圆杆。
4. **受约束修正**：原件姿态可行时保持几何；需要且允许修改时，候选受径向增长、增材体积及允许区域约束，再次切片与复核。
5. **交付**：核对源模型、候选、配置和G-code指纹，重新验证变换与刀轨指标。没有满足硬约束的候选时停止交付。

## 代码入口

- `src/print-server.mjs`：本地工作台服务。
- `src/pose-jobs.mjs`、`src/pose-comparison.mjs`：候选执行、筛选和交付状态。
- `src/support-evaluation.mjs`：源坐标保护区的支撑统计。
- `src/critical-feature-audit.mjs`、`src/rod-toolpath-continuity.mjs`：特征及整段细杆刀轨检查。
- `src/repair-jobs.mjs`、`src/local-repair-service.mjs`：局部修正、预算及复核。
- `tools/review/run.mjs`：已有样例的文件和刀轨复核。

## 使用范围

现有结果证明软件几何与计划刀轨满足声明的检查条件，不等于实际成型、装配精度或机械强度已通过实验。候选排序只针对已经测试并通过约束的姿态，不声称全局最优。模型权重、账号与开发机任务数据库不随仓库分发。

配置和运行统一见根目录[运行与模型配置](../运行与模型配置.md)。
