# 完整对象验证：固定尺寸路灯与连续性误判修复

本轮完成一个原创参数化沙盘路灯设计的完整切片与受约束修正案例，发现并修复了“表面采样通过但实际刀轨仍断层”的验收漏洞。**这是一项软件设计验证，不是实拍重建、真实用户测试或实物打印成功。**

## 任务与固定要求

路灯整体12×8×30mm，底座12×8×2mm，灯头直径5mm、高2mm，26mm杆段位于z=2..28。原杆直径0.5mm；底座另有直径2mm定位通孔。要求固定整体尺寸、保留定位孔，局部最大径向增长0.2mm、新增体积不超过20mm³。原设计与特征范围公开为原创参数化示例，没有伪造摄影来源或客户访谈。

生成/复现入口：`tools/reconstruction/scale_lamppost_case.py`。本轮导入归一化前后STL字节SHA相同；驱动新增强制断言，坐标发生变化时停止，不把原ROI直接套到变换后的模型。

## 实际对照

原源SHA：`7b018923c6e0350b774fec4e9ca3829dcc83e3b84bb043946684646fce781129`。使用固定虚拟PLA/0.4mm喷嘴/0.2mm层高、自动支撑和PrusaSlicer2.9.6。现有配置本来就启用Arachne，没有故意关闭薄壁处理。

四种原源姿态均未达到声明的实体表面90%阈值。直立保留率6.25%，X+30°约78.67%、X−30°约72.54%、Y+30°为0；每个定位孔仍连通。独立复制配置中的75%/60%最小线宽敏感性实验，仅同时调整最小特征尺寸至10%，也未恢复杆；除此之外，层高、支撑、尺寸等设置未改。这个结果只涵盖上述有限选择，不代表所有调参或姿态无效。

## 真正修复的验收问题

首次原生AGH修正任务 `b35069fa-3ed7-4e18-8232-c35105454911` 在旧表面采样规则下交付0.7mm。独立审查与root复算证明，该杆段实际存在17处未覆盖空档，累计约4mm；例如z=8..8.4、8.6..9、13.2..13.6。32层采样步距0.796875mm跳过了部分实际层，因此96.875%不能证明整段连续。原记录未改写，保存为误判反例。

新增 `rod-toolpath-continuity.mjs`：将原声明中心线通过已验证的姿态及热床偏移变换，计算其与正向MODEL挤出线宽胶囊及实际HEIGHT厚度区间的连续交集，按区间并集检查全段覆盖。支撑、空走、回抽不补空；未知角色/宽高、弧线、非平面挤出、无效变换或资源超限均不能通过。2e-6mm仅用于数字序列化微小缝，不是制造公差。

这证明的是中心线与计划挤出包络的关系，不是完整截面、机械强度、热稳定性或实际打印可靠性。通用solid表面采样仍按原声明语义处理；单直圆杆修正另外增加此硬要求，没有把所有曲面都叫作可自动修复。

## 检视、交付和速度

检视STL仍可查看原源和失败候选。正式交付新增独立delivery链接，要求已提交候选及SHA，并重检当前来源、几何、切片、原/新特征和中心线。旧0.7mm正式交付返回400 `ROD_TOOLPATH_DISCONNECTED`；保留其可检视性。UI旧记录显示“尚未复核连续性”并禁用正式下载。

最终正式文件77784字节，SHA：`f4207850ca8ed78ca7e10c2135fc62bd074353d643ea99854d2ddef9580b8c0d`。实际HTTP与两次浏览器下载文件均匹配。浏览器的Blob下载事件监听未捕获，但文件落盘、SHA和页面状态已确认，没有据事件超时宣称下载失败。

性能定位：几何复查约1.7s，两套相同探针各约25–27s，采样包络审计合计约0.3s、连续性约18ms。现复用本进程/同执行器已实际生成、验证过的相同探针。每次仍读源、探针、helper字节，核对内联数据、声明和recipe；同步伪造新哈希会miss并真正重算。进程重启后冷复核53.24s，同输入复用后实际HTTP2.01s，字节/SHA一致。修改依赖或代码需重启服务；不把缓存命中称作每次重跑几何helper。
