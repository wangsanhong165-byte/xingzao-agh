完整复现顺序

  1. 准备Node.js、Python3.12和Git；脚本安装项目依赖及PrusaSlicer。
  2. 构建固定版本AGH，配置自己的模型账号，安装四个业务插件。
  3. 运行源码中的启动.bat，打开http://127.0.0.1:4337/，先导入STL执行制造任务。
  4. 需要照片建模和上色时，再批量下载模型，准备GPU环境与原生扩展。
  5. 结果页下载模型与刀轨，在AGH中导出本次执行日志。

所有命令、下载地址、预期输出和排错统一在运行与模型配置.md。模型按需下载，复现者自行配置账号。
